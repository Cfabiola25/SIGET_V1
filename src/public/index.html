Infraestructura y Despliegue

Arquitectura Docker Multi-Contenedor

Diseñado para ejecutarse en entornos de alta disponibilidad con balanceo de carga, proxy inverso Nginx y base de datos relacional MySQL 8.0 aislada.

01

siget_web (Nginx)

Proxy inverso en Alpine Linux (Puerto 80:80). Compresión Gzip, streaming SSE para eventos en vivo y distribución optimizada de assets estáticos.

02

siget_app (PHP 8.5)

Entorno Laravel 13 con extensiones nativas pdo_mysql, intl, gd, zip y aceleración Opcache.

03

siget_db (MySQL 8.0)

Base de datos transaccional en Puerto 3306 con volumen persistente db_data, healthchecks automáticos y claves foráneas en cascada.

🚀 Comandos de Inicialización (Producción / Local) Bash / Terminal 
# 1. Levantar la infraestructura completa en segundo plano
docker compose up -d --build

# 2. Generar llave criptográfica y migrar base de datos con seeders oficiales
docker compose exec -T app php artisan key:generate
docker compose exec -T app php artisan migrate:fresh --seed
